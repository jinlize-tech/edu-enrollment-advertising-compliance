# JLZ-EDU-SK-082 Codex执行任务书

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`

## 2. 用户、痛点与目标

- 用户：校长、市场主管、招生主管、新媒体运营、课程顾问
- 痛点：招生文案常在发布前才检查，容易混入保分、名师押题、限时名额、升学承诺或未经授权的案例与肖像。
- 目标：在发布前按渠道逐条审查文案、图片说明、短视频口播和直播要点，输出风险等级、证据缺口与合规改写版本。

## 4. 工作流

1. 确认适用地区与业务类型
2. 提取宣传承诺
3. 检查敏感词与事实依据
4. 检查案例肖像授权
5. 标记风险等级
6. 给出守边界改写
7. 人工复核清单

## 6. 核心成果

## 7. 差异化与排重

- 与现有产品：现有小红书/朋友圈/短视频/直播产品负责生成内容；本产品只做发布前独立合规审查，并覆盖多渠道统一风控。
- 排重检查：部分重叠；现有产品以内容生成为主，本产品以独立审查、风险分级、证据核验和驳回/整改为交付核心。
- 独立理由：机构可以只安装本产品审查任何来源的招生素材，不要求先用现有内容生成器。

## 8. 安全与人工门禁

- 复核角色：合规负责人/法律专业人员
- 复核范围：所有高风险宣传承诺、真实案例、未成年人代言和优惠稀缺性表述
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
