# 招生宣传合规预审领域指南

## 业务问题

招生文案常在发布前才检查，容易混入保分、名师押题、限时名额、升学承诺或未经授权的案例与肖像。

## 产品解决方案

在发布前按渠道逐条审查文案、图片说明、短视频口播和直播要点，输出风险等级、证据缺口与合规改写版本。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `region` | 机构地区 | 是 | 用于提示地方规则差异 |
| `business_type` | 业务类型 | 是 | 例如学科、素质、成人技能或企业培训 |
| `channel` | 发布渠道 | 是 | 文案、海报、短视频、直播等 |
| `content_text` | 原始宣传内容 | 是 | 待审查的完整原文 |
| `course_and_price` | 课程与价格信息 | 是 | 宣传涉及的真实课程及价格 |
| `promotion_rules` | 优惠与名额规则 | 否 | 活动机制、名额和期限 |
| `case_authorization_status` | 案例与肖像授权状态 | 否 | 真实案例、评价和肖像是否获授权 |
| `target_audience` | 目标受众 | 是 | 尤其说明是否面向未成年人或家长 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

合规负责人/法律专业人员应确认：所有高风险宣传承诺、真实案例、未成年人代言和优惠稀缺性表述。未经确认的内容只能作为草案。

## 主要风险

不能把模型判断当作法律结论；地区政策与教育培训类别差异需人工复核；不得自动发布或替机构作最终审批。
